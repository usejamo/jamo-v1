## What Was Built

**Migration 000031** adds a nullable `tool_data JSONB` column to `proposal_chats`. This column stores structured AI tool result payloads (propose-edit, answer-cited, compliance, etc.) and is `NULL` for plain chat messages. It inherits the existing proposal_chats RLS (org-scoped SELECT/INSERT/UPDATE).

**Migration 000032** creates the `chat_sessions` table:
- `proposal_id` unique index (one session per proposal)
- `active_task`, `pending_actions`, `resolved_items` as JSONB for state tracking
- `current_focus_section` text for section context
- RLS enabled with `chat_sessions_org_isolation` policy using `auth.jwt() ->> 'org_id'` cast
