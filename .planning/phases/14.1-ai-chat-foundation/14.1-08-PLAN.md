**Change 3: State mutation persistence — UPDATE tool_data.state**

Add a helper function inside the component:
```typescript
const persistToolDataState = useCallback(async (messageId: string, newState: Record<string, unknown>) => {
  // Read current tool_data first (optimistic update already applied to local state)
  const msg = messages.find(m => m.id === messageId)
  if (!msg?.toolData) return
  try {
    await supabase
      .from('proposal_chats')
      .update({
        tool_data: { ...msg.toolData, state: newState } as unknown as Json,
      })
      .eq('id', messageId)
  } catch {
    // Silent fail per D-07 convention
  }
}, [messages])
```

Wire this into the onAccept, onReject, onDismiss, and onAnswer handlers in the message render:
