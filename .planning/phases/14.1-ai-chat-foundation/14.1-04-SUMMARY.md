# Phase 14.1 Plan 04: chatContext + SectionEditorBlock Upgrade Summary

**One-liner:** HTML paragraph IDs sent to AI via upgraded buildContextPayload, and applyParagraphPatch exposed on TipTap editor ref via UniqueID extension.

## What Was Built

### Task 1: chatContext.ts Upgrade

- **sectionKeyToTitle** — new export converting snake_case keys to Title Case with optional override map
- **buildSlidingWindow** — default budget upgraded from 8000 to 42000 chars (~12k tokens at chars/3.5)
- **buildContextPayload** — `target_section.content` now passes HTML with paragraph `data-id` attributes intact (not stripped); both `target_section.title` and `other_sections[].title` use `sectionKeyToTitle`; accepts optional `sectionTitles` map (D-06)

### Task 2: SectionEditorBlock + workspace.ts

- **@tiptap/extension-unique-id** installed; UniqueID registered on `paragraph` and `heading` nodes with `attributeName: 'id'`
- **PatchResult** interface added to workspace.ts (`{ applied: number, stale: string[] }`)
- **applyParagraphPatch** added to `SectionEditorHandle` interface and implemented in `useImperativeHandle`:
  - `replace`: finds node by `data-id`, calls `insertContentAt` with range replacement
  - `delete`: finds node, dispatches `tr.delete` with `addToHistory: true` for undo
  - `insert_after`: finds anchor node, inserts at `anchorPos + anchorSize`
  - Stale ID detection: all unresolved IDs returned in `stale[]` array, no content corruption
