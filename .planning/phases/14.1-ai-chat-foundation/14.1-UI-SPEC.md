## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps (`gap-1`), badge padding |
| sm | 8px | Chip padding, compact element spacing (`gap-2`, `px-2`) |
| md | 16px | Default element spacing (`px-4`, `py-4`) |
| lg | 24px | Section padding, panel header area (`py-3.5 px-4`) |
| xl | 32px | Layout gaps between major areas |
| 2xl | 48px | Not used in this panel phase |
| 3xl | 64px | Not used in this panel phase |

Touch target minimum: 24px (w-6 h-6) for icon-only buttons.

Note: Existing component classes (AuroraBorder, Rail, SpectrumSparkle, bubble sizing) are inherited unchanged and are not subject to this spacing contract. Values such as `px-3.5`, `py-2.5`, and `px-3.5` exist in these inherited components but are not new spacing decisions made in this phase.

Source: `AIChatPanel.tsx` existing class audit.

## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body / chat message | 12px (`text-xs`) | 400 (regular) | 1.5 (`leading-relaxed`) | Message bubble content, card body text |
| Label / UI chrome | 12px (`text-xs`) | 600 (semibold) | 1 | Panel header "jamo AI", section titles, tool status label |
| Caption | 10px (`text-[10px]`) | 400 (regular) | 1 | Keyboard shortcut hint, gap badge count, rail writing-mode label |
| Metadata | 12px (`text-xs`) | 400 (regular) | 1 | "Proposal assistant" subtitle, "Live" status, citation source chips |

Rules:
- Maximum 4 sizes in this panel — 10px, 12px, 14px (if needed for DiffPreview paragraph context), and no larger.
- 2 weights only: 400 regular + 600 semibold. No medium (500) weight is used.
- Caption role uses `font-normal` (400) — captions at 10px with semibold risk illegibility.
- Panel header name: `text-sm font-semibold text-gray-900 leading-none` — matches existing exactly.

Source: `AIChatPanel.tsx` typography audit.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#F9FAFB` (gray-50) | App background surface |
| Secondary (30%) | `white/92` with `backdrop-blur-md` | Panel inner surface (`bg-white/92 backdrop-blur-md`) |
| Accent (10%) | `#6c29df` (`jamo-500`) | Reserved list below |
| Destructive | `#EF4444` (red-500) | Discard/reject actions only |
| Semantic: success | `#34D399` (emerald-400) | Live status dot, accepted paragraph indicator |
| Semantic: warning | `#F59E0B` (amber-400) | Compliance flag severity: warning level |

Accent `#6c29df` reserved for:
- Gap count badge on `SpectrumSparkle` (existing: `bg-jamo-500`)
- Tool status label text when a tool is actively running (e.g. "Drafting your edit...")
- "Accept edit" button on `DiffPreview` paragraph rows
- Focus section chip highlight border

Destructive `red-500` reserved for:
- "Discard suggestion" button on stale-paragraph warning ("This paragraph was removed — discard suggestion?")
- "Reject all" bulk action if implemented

Source: `src/index.css` `@theme {}` + `AIChatPanel.tsx` color audit.

### Aurora Border (existing — do not change)

The `AuroraBorder` component wraps the full panel with an animated gradient border (`jamo-aurora` / `jamo-aurora-fast`). This is the primary visual anchor and brand expression of the AI panel. New tool result cards live inside the panel — they must NOT use aurora effects internally. Aurora is exclusive to the outer panel wrapper and the `SpectrumSparkle` rail icon.

## Interaction States

### Tool Status Label (new in 14.1)

When the edge function sends `{ type: 'tool_start', tool: <name> }`, replace the three-dot thinking indicator with a labeled status. The label replaces dots — it does not appear alongside them.

| State | Visual |
|-------|--------|
| No tool running, no stream | Input enabled, chips enabled |
| Tool starting (`tool_start` event received) | Dots replaced by status label in `text-jamo-500 text-xs font-semibold` inside the existing thinking bubble position |
| Tool complete (`tool_result` received) | Label disappears; tool result card renders below |
| Plain text stream (no tool) | Dots appear, then stream renders inline as today |

Status label copy (from `TOOL_STATUS_LABELS` constant — D-05):
- `propose_edit` → "Drafting your edit..."
- `answer_with_citations` → "Finding sources..."
- `check_regulatory_compliance` → "Checking compliance..."
- `ask_user` → "Working..."
- `set_focus` → "Working..."

Tone convention: present-progressive, implied first-person. Document this next to the constant.

Fallback for unknown tool names: render "Working..." — never undefined.

### DiffPreview Component (new)

Renders inside an assistant message bubble for `tool-propose-edit` message type.

| Element | Spec |
|---------|------|
| Container | `rounded-xl border border-gray-200 bg-white overflow-hidden` |
| Paragraph row | `border-b border-gray-100 last:border-0 px-3 py-2.5` |
| Before text | `text-xs text-gray-400 line-through leading-relaxed` (strikethrough) |
| After text | `text-xs text-gray-800 leading-relaxed mt-1` |
| Accept button | `text-xs font-medium text-jamo-600 hover:text-jamo-700 px-2 py-0.5 rounded bg-jamo-50 hover:bg-jamo-100 transition-colors` — label: "Accept edit" — `aria-label="Accept edit"` |
| Reject button | `text-xs text-gray-400 hover:text-gray-600 px-2 py-0.5 rounded hover:bg-gray-100 transition-colors` — label: "Reject edit" — `aria-label="Reject edit"` |
| Accepted state | Row gets `bg-emerald-50/50`; Accept button replaced by `text-xs text-emerald-600 font-medium` "Accepted" label |
| Rejected state | Row gets `opacity-40 line-through`; Reject button replaced by `text-xs text-gray-400` "Discarded" label |
| Stale paragraph | `bg-amber-50 border-l-2 border-amber-400` with copy: "This paragraph was removed — discard suggestion?" + Discard button in `text-xs text-red-500` — label: "Discard suggestion" — `aria-label="Discard suggestion"` |

### CitationsBlock Component (new)

Renders below answer text for `tool-answer-cited` message type.

| Element | Spec |
|---------|------|
| Container | `mt-2 flex flex-wrap gap-1.5` |
| Citation chip | `text-[10px] text-gray-500 bg-gray-100 hover:bg-gray-200 border border-gray-200 rounded-full px-2 py-0.5 cursor-default` |
| Chip label | Document short name + chunk reference, e.g. "ICH E6(R2) §5.1" |

### ComplianceCard Component (new)

Renders for `tool-compliance` message type.

| Element | Spec |
|---------|------|
| Container | `rounded-xl border bg-white overflow-hidden` |
| Flag row | `flex items-start gap-2 px-3 py-2 border-b border-gray-100 last:border-0` |
| Severity dot | `w-2 h-2 rounded-full mt-1 shrink-0` — `bg-red-500` critical, `bg-amber-400` warning, `bg-blue-400` info |
| Flag message | `text-xs text-gray-700 leading-relaxed` |
| Flag source | `text-[10px] text-gray-400 mt-0.5` |
| Dismissed state | Row `opacity-40`; dismiss icon (X) at row right: `w-3.5 h-3.5 text-gray-300 hover:text-gray-500 cursor-pointer` |

### AskUserCard Component (new)

Renders for `tool-ask-user` message type.

| Element | Spec |
|---------|------|
| Container | `rounded-xl border border-blue-200 bg-blue-50/40 px-3 py-2.5` |
| Question text | `text-xs text-gray-800 leading-relaxed` |
| Answer input | `mt-2 w-full text-xs bg-white border border-gray-200 rounded-lg px-2.5 py-1.5 outline-none focus:border-jamo-400 placeholder-gray-400` |
| Submit button | `mt-1.5 text-xs font-medium text-white bg-gray-900 hover:bg-gray-700 px-3 py-1 rounded-lg transition-colors disabled:opacity-30` |
| Answered state | Input replaced by `text-xs text-gray-600 italic` showing submitted answer |

### Send Button Accessibility

The send button (arrow icon, no visible label) must include `aria-label="Send message"`.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA (send) | No label — arrow icon only (matches existing send button); `aria-label="Send message"` |
| Input placeholder | "Ask jamo to edit..." (keep existing) |
| Tool status: propose_edit | "Drafting your edit..." |
| Tool status: answer_with_citations | "Finding sources..." |
| Tool status: check_regulatory_compliance | "Checking compliance..." |
| Tool status: ask_user / set_focus | "Working..." |
| Tool status: unknown fallback | "Working..." |
| DiffPreview accept button | "Accept edit" |
| DiffPreview reject button | "Reject edit" |
| DiffPreview accepted state | "Accepted" |
| DiffPreview discarded state | "Discarded" |
| DiffPreview stale paragraph | "This paragraph was removed — discard suggestion?" |
| DiffPreview stale action | "Discard suggestion" |
| ComplianceCard dismiss | No label — X icon only with `aria-label="Dismiss flag"` |
| AskUserCard submit | "Reply" |
| AskUserCard answered label | (shows the user's actual answer text, italicized) |
| Empty state: no messages | Not applicable — gap messages inject automatically on panel open |
| Error: tool_data upsert failure | Silent fail (no UI notification) — matches compliance flag upsert convention (D-07) |
| Error: stale paragraph ID | "This paragraph was removed — discard suggestion?" (inline in DiffPreview row) |

| Set focus confirmation | No confirmation UI — `set_focus` takes effect silently; section highlight is the feedback |

No destructive confirmation dialogs in 14.1. The only destructive-adjacent action (Reject edit / Discard suggestion) is reversible within the session (tool_data.state tracks per-paragraph status but no hard delete occurs).
