## Decisions Made

1. **Inline SVG for dismiss icon** — `lucide-react` is not in the project's dependencies. Used an inline SVG X path matching the same visual spec. Avoids adding a dependency for a single icon.

2. **set_focus stays silent** — Per UI-SPEC, `tool-set-focus` requires no visible card. The old combined fallback `<p>` was removed; set_focus messages simply render nothing inside the tool card wrapper.

3. **Answer injection as ChatMessage** — When a user submits an AskUserCard answer, it's appended as a new `role: 'user'` ChatMessage so the AI sees it in conversation history on the next turn.
