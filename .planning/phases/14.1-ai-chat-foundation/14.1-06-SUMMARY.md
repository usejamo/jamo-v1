## What Was Built

**DiffPreview** (`src/components/chat/DiffPreview.tsx`): Renders one row per `ProposeEditChange`. Accepted rows show `bg-emerald-50/50` + "Accepted" label; rejected rows show `opacity-40`; stale rows show `bg-amber-50 border-l-2 border-amber-400` with "This paragraph was removed — discard suggestion?" copy. `before_html`/`after_html` rendered via `dangerouslySetInnerHTML` (display-only). Accept button calls `onAccept(paragraphId, change)`; reject button calls `onReject(paragraphId)`.

**CitationsBlock** (`src/components/chat/CitationsBlock.tsx`): Renders nothing on empty citations array. Each citation displays as a `rounded-full` chip showing `citation.source` with `citation.passage` as tooltip title.

**ToolStatusLabel** (`src/components/chat/ToolStatusLabel.tsx`): Looks up `TOOL_STATUS_LABELS[toolName]` and renders `<span className="text-jamo-500 text-xs font-semibold">`. Returns null when `toolName` is null.

**AIChatPanel wiring**: `tool-propose-edit` messages now render DiffPreview with accept/reject handlers that call `editor.applyParagraphPatch([change])` via editorRefs and update local `resolutions` state. `tool-answer-cited` messages render CitationsBlock. Thinking bubble uses ToolStatusLabel instead of inline span.
