## What Was Built

The `handleCheckCompliance` function in the edge function tool handler now:
1. Maps `ComplianceIssue[]` (tool schema) to `ComplianceFlag[]` (workspace.ts shape): `critical→fail`, `warning→warning`, `info→warning`, `source: 'haiku'`
2. Writes the flags to `proposal_sections.compliance_flags` via a Supabase service role client (same pattern as `set_focus`)
3. Uses silent-fail (`try/catch` with no rethrow) — compliance flags are non-blocking per D-08
4. Function made `async`; `index.ts` updated to `await` the call and pass `proposal_id` / `org_id`

The existing `useComplianceCheck` hook is untouched — both the hook and the tool write the same `ComplianceFlag[]` shape to the same column (last-write-wins, acceptable per threat register T-14.1-27).
