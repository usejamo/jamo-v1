## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Correctness] null vs empty-array therapeutic_areas_filter**
- **Found during:** Task 2
- **Issue:** The pre-existing code derived `therapeuticAreas = therapeuticArea ? [therapeuticArea] : []`. With the RPC predicate `filter IS NULL OR x = ANY(filter)`, an empty array is NOT null, so `= ANY('{}')` is always false → every row excluded. Harmless while the corpus was empty, but wrong once populated.
- **Fix:** Derive `null` when the attribute is absent (`therapeuticArea ? [therapeuticArea] : null`), so the RPC skips the filter. Same null-when-absent rule for phases/geographies.
- **Verification:** Direct RPC call with populated + null filters executes; relaxation level 2 passes null TA.

---

**Total deviations:** 1 auto-fixed (correctness). **Impact:** Prevents a would-be "regulatory always empty" bug once the corpus is ingested. No scope creep.
