# Phase 14.5 Plan 06: Geography Wiring Summary

**Geography is now a first-class proposals column round-tripped end to end: the wizard writes proposals.geography (dropping the regions key from the description blob), buildProposalInput reads it into studyInfo.countries, and the legacy description.regions reader is retired with no remaining references.**

## Performance

- **Duration:** ~15 min
- **Completed:** 2026-07-08
- **Tasks:** 2
- **Files modified:** 4

## Accomplishments
- `Proposal` type gains `geography?: string[]`; `ProposalsContext` round-trips it in mapRow, createProposal insert, and updateProposal conditional.
- Both wizard `createProposal` calls now pass `geography: studyInfo.regions` and write `description: JSON.stringify({ services: studyInfo.services })` (regions key gone).
- `ProposalDetail.buildProposalInput` reads `countries: proposal?.geography ?? []` instead of the description blob.
- Full suite green (327 passed); no new tsc errors in modified files.
