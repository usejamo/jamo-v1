## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Correctness] Drop stale pre-join RPC overloads**
- **Found during:** Task 1 (rewrite regulatory match RPCs)
- **Issue:** The new signatures add `phases_filter`/`geographies_filter`, so `CREATE OR REPLACE` registers NEW overloads and leaves the OLD 6-arg vector / 5-arg fts signatures callable — returning stale results from the now-always-NULL `chunks.agency/therapeutic_area`. This is exactly the silent-drift hazard the BRIEF warns about.
- **Fix:** Added `DROP FUNCTION IF EXISTS match_chunks_vector(extensions.vector(1536), UUID, TEXT[], TEXT[], FLOAT, INT);` and `DROP FUNCTION IF EXISTS match_chunks_fts(TEXT, UUID, TEXT[], TEXT[], INT);` before the CREATEs.
- **Files modified:** supabase/migrations/20260708000004_regulatory_match_rpcs.sql
- **Verification:** grep confirms drops present; only the joined signatures remain.
- **Committed in:** `49dd5ca`

Also reworded an inline comment so the file does not literally contain the proposal-RPC names (acceptance criterion requires their absence) — no functional change.
