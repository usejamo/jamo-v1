# Phase 14.6 Plan 01: Split RAG Payload Contract Summary

**Replaced the merged `ragChunks` array on `GenerateSectionPayloadV2` with three explicit fields (regulatoryChunks, proposalChunks, regulatoryCount) and threaded the split through `fetchRagChunks` → `streamSection` → the edge payload, so tier identity and retrieval count survive to generate-proposal-section instead of being collapsed and dropped.**

## Accomplishments
- `src/types/generation.ts`: added exported `RagChunk` interface; `GenerateSectionPayloadV2.ragChunks` fully removed and replaced with `regulatoryChunks: RagChunk[]`, `proposalChunks: RagChunk[]`, `regulatoryCount: number`
- `src/hooks/useProposalGeneration.ts`: `fetchRagChunks` no longer merges `[...regulatory, ...proposal]` — it returns the split object with `regulatoryCount` sourced from `retrievalMeta.regulatoryCount`; both failure paths (`error` and `catch`) return a symmetric zeroed shape
- `streamSection` now takes a single `rag` param typed to the split shape and spreads it into the three payload fields; `generateAll` and `generateSection` call sites updated to pass the renamed `rag` local through unchanged
