
### new migration — `CREATE OR REPLACE ingest_regulatory_document` (migration) — CREATE

**Analog (edit ONE branch):** `supabase/migrations/20260708000005_ingest_regulatory_rpc.sql`.

**Current supersession branch (lines 40–49) — the silent no-op:**
```sql
IF p_supersedes_document_key IS NOT NULL THEN
  SELECT id INTO v_supersedes_id FROM regulatory_documents
    WHERE document_key = p_supersedes_document_key AND status = 'active' AND id <> v_id;
  IF v_supersedes_id IS NOT NULL THEN          -- <-- falls through silently when NULL
    UPDATE regulatory_documents SET status = 'superseded', superseded_by = v_id, updated_at = NOW()
      WHERE id = v_supersedes_id;
    UPDATE regulatory_documents SET supersedes = v_supersedes_id, updated_at = NOW()
      WHERE id = v_id;
  END IF;
END IF;
```
**Required change (from BRIEF):** after the SELECT, RAISE when `v_supersedes_id IS NULL` **but only inside the `p_supersedes_document_key IS NOT NULL` branch** (the outer IF already guarantees a key was passed):
```sql
IF v_supersedes_id IS NULL THEN
  RAISE EXCEPTION 'supersedes target % not found among active regulatory_documents',
    p_supersedes_document_key;
END IF;
-- ... existing two UPDATE flips (unchanged) ...
```
**Do NOT** raise at the top level on `v_supersedes_id IS NULL` — that would fire on every non-superseding ingest (all GLOBAL starter docs) and break seeding. When `p_supersedes_document_key IS NULL` the whole block is skipped — correct, keep it.

**Preserve verbatim** the rest of the function: full arg list (lines 8–20), `LANGUAGE plpgsql SECURITY DEFINER SET search_path = public, extensions` (line 21), the upsert-in-place (`document_key` NEVER in the UPDATE SET, line 37), the parent-scoped `DELETE FROM chunks WHERE regulatory_document_id = v_id` (line 51), the jsonb chunk insert (53–57), and the **REVOKE/GRANT footer (lines 63–66)** — re-emit it identically or the direct anon/authenticated grants reappear.

```ts
const regSection = regulatoryChunks.length > 0
  ? regulatoryChunks.map(c => `[${c.source}] ${c.content}`).join('\n\n')
  : '(No relevant regulatory context found)'

  ? proposalChunks.map(c => `[${c.source}] ${c.content}`).join('\n\n')
```
