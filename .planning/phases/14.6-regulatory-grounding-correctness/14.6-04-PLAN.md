## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14.6-07 | Info disclosure | OPENAI_API_KEY / SUPABASE_SERVICE_ROLE_KEY | mitigate | Load only via loadEnv() from env (never hardcode/log); createClient with persistSession:false; keys never written to files or stdout. |
| T-14.6-08 | Tampering (arbitrary file read) | manifest `folder` → filesystem path | mitigate | Constrain reads to `regulatory-docs/<folder>` under the repo docsRoot; reject folder values containing path separators / `..` in validateManifest (treat as a validation error). Only `*.pdf` files are read. |
| T-14.6-09 | DoS / cost | embedding spend on bad batch | mitigate | Pre-validation aggregates all failures and exits non-zero before any embedBatch call; all-or-nothing at batch level. |
