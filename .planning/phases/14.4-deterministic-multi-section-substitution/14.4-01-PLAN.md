<objective>
Build the ONE genuinely-new deterministic primitive for Phase 14.4: a pure, unit-tested module that locates placeholder spans by `data-placeholder-id`, substitutes the literal supplied value into the containing paragraph (stripping the placeholder mark), groups multiple targets per paragraph into a single composed `after_html`, builds synthetic paragraph-replace `PendingEdit`s, and reconciles proposed-vs-actual outcomes into honest counts + a chat one-liner.

This is Wave 0 (the Nyquist gate): everything client-side downstream (the fan-out in AIChatPanel, the aggregate card) consumes these pure functions and their types. No editor instance, no SSE, no React — just strings in, strings/structs out, byte-identical on repeat (SPEC R3).

Purpose: Collapse the SPEC's named "span→paragraph granularity bridge" gap into a small pure module the rest of the pipeline treats as ordinary paragraph replaces (D-07/D-08/D-09).
Output: `src/editor/placeholders/substitute.ts` + two vitest specs, all green.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model proposal → client doc-walk | The tool's `targets` are an untrusted CLAIM; the live doc is the truth (D-04). |
| value → after_html | User-supplied literal string is inserted into paragraph HTML. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14.4-01 | Tampering | resolvePlaceholderTarget on a model-proposed placeholder_id | mitigate | Client is authoritative (D-04): an id absent from the live section HTML returns null → caller makes it a skip, never a blind write. Unit-tested (absent id + no-data-id-ancestor → null). |
| T-14.4-02 | Injection (XSS) | buildSubstitutedParagraphHtml inserting `value` | mitigate | Value is inserted via `doc.createTextNode(value)` (text node), never as parsed HTML — angle brackets/scripts are escaped by the DOM. Same-origin, no innerHTML of user value. |
| T-14.4-03 | Info disclosure | Cross-section leakage in grouping | accept | Pure functions operate only on the single `sectionHtml` string passed in; no cross-section state. Fan-out (Plan 04) passes each section its own HTML. |
</threat_model>
