# Phase 14.4 Plan 01: Deterministic Locate/Substitute/Group/Reconcile Primitives Summary

Pure, unit-tested TypeScript module (`src/editor/placeholders/substitute.ts`, 227 lines) that
locates `data-placeholder-id` spans by id, substitutes a literal value into the containing
paragraph while stripping the placeholder mark, groups multiple targets in one paragraph into a
single composed `after_html`, builds synthetic paragraph-replace `PendingEdit`s, and reconciles
proposed-vs-actual outcomes into an honest applied/skipped tally plus a chat one-liner.

## What Was Built

**Task 1 — Locate + substitute + group** (`resolvePlaceholderTarget`, `groupTargetsByParagraph`,
`buildSubstitutedParagraphHtml`): Uses `DOMParser` to parse paragraph/section HTML, iterates
`querySelectorAll('[data-placeholder-id]')` and compares `getAttribute` (no CSS attribute
selector, since `CSS.escape` may be absent in happy-dom — Pitfall 3). `resolvePlaceholderTarget`
walks up via `.closest('[data-id]')` to find the containing paragraph; returns `null` on an
absent id (R2 — no fuzzy fallback) or a span with no `data-id` ancestor (Pitfall 2). Two spans in
one paragraph produce ONE composed `after_html` via `groupTargetsByParagraph` + a single
`buildSubstitutedParagraphHtml` call over both ids (D-09). The value is inserted via
`doc.createTextNode(value)`, never parsed HTML — mitigates T-14.4-02 (XSS).

**Task 2 — Edit-builder + reconciler** (`buildSectionPendingEdits`, `reconcileOutcome`,
`composeChatSummary`): `buildSectionPendingEdits` emits one synthetic `replace` `PendingEdit` per
paragraph group, with `id` namespaced `${bulkMsgId}-${section_key}-${i}` (Pitfall 4 — globally
unique across the fan-out) and never sets `anchor_hash`/`anchorFrom`/`anchorTo` (materialize-time
and runtime-only fields respectively). `reconcileOutcome` merges model-declared skips
(genuine multi-part) and client-side resolution failures (unresolvable) into one `skipped[]`,
clamping `applied` to `resolvedSubstitutions.length` so an unresolved proposed-substitute target
can never be double-counted (D-15). `composeChatSummary` emits the three R7 one-liner shapes:
full / partial / zero-match.
