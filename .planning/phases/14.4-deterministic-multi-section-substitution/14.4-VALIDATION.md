**Environment carve-outs (why some tasks are static/grep, not `<automated>`):**
1. **Edge (Deno) code** — `supabase/**` is excluded from vitest and Deno is unavailable in this dev environment (established in Phase 14.3). Edge tasks (Plan 02: tool file + registration + system prompt; Plan 05: deploy) verify via **grep/static acceptance** on the source, exactly as 14.3's edge plans did.
2. **React components** — `@testing-library/react` pulls `react-dom` and OOMs on this dev machine (recorded in STATE). Presentational/callback components (Plan 03 `BulkSubstitutionSummaryCard`; Plan 04 `AIChatPanel` wiring) verify via **`tsc` + grep** for the required symbols/props, with live behavior proven in Plan 05 UAT.

These carve-outs are the reason Wave 1 has consecutive non-`<automated>` tasks — it is **intentional and sanctioned**, not a sampling gap. The deterministic core (Plan 01) IS fully `<automated>` and is the load-bearing correctness gate; every behavioral outcome that can't be unit-tested is captured in the **Manual-Only** table and gated by Plan 05 before verify.
