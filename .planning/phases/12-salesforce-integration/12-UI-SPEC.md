## Component Inventory

### SalesforceConnection

File: `src/components/SalesforceConnection.tsx`

Replaces the `Salesforce` entry in the `INTEGRATIONS` array in `src/pages/Settings.tsx`. Placed first in the `grid grid-cols-3 gap-5` grid (before HubSpot and Workday). After removal of Salesforce from the static array, the grid will have 2 static cards + 1 dynamic card = 3 total. Grid stays `grid-cols-3`.

#### State Machine

```
idle (disconnected) ──[click Connect]──► loading
loading             ──[fetch auth_url]──► redirect (browser leaves page)
idle (disconnected) ◄──[sf_error param]── error
error               ──[dismiss × ]──► idle (disconnected)
idle (connected)    ──[click Disconnect]──► disconnecting
disconnecting       ──[success]──► idle (disconnected)
disconnecting       ──[error]──► idle (connected) + inline error
```

#### Disconnected State Layout

```
┌─────────────────────────────────────────────────┐
│  [SF logo]  Salesforce                           │
│             CRM pipeline and opportunity mgmt    │
│─────────────────────────────────────────────────│
│  ○ Production  ● Sandbox     [Connect Salesforce]│
└─────────────────────────────────────────────────┘
```

- Outer card: `bg-white rounded-xl border border-gray-200 p-5 flex flex-col gap-4`
- Header row: SF logo (24px max-height) + name (`text-sm font-semibold text-gray-900`) + description (`text-xs text-gray-500 mt-0.5`)
- Footer row: `flex items-center justify-between pt-3 border-t border-gray-100`
  - Left: Radio group — Production (default) / Sandbox, `flex items-center gap-4`, each radio `flex items-center gap-1.5 text-xs text-gray-600`
  - Right: "Connect Salesforce" button — `text-xs font-medium text-jamo-600 hover:text-jamo-700 border border-jamo-200 hover:border-jamo-300 px-3 py-1.5 rounded-lg transition-colors`
- Loading state (after click, before redirect): button shows inline spinner (16px, `animate-spin`, `text-jamo-500`) + "Connecting…" text; button is `disabled` and `opacity-60`

#### Connected State Layout


## Interaction Contracts

### URL Parameter Handling (D-15)

On component mount:
1. Read `sf_error` from `useSearchParams()`
2. If present, map to error copy (D-14) and set local error state
3. Immediately call `window.history.replaceState({}, '', location.pathname + location.search.replace(/[?&]sf_error=[^&]*/g, '').replace(/^&/, '?'))` to strip param
4. Banner renders; user sees error without `sf_error` reappearing on refresh

### OAuth Initiation Sequence

1. User selects Production (default) or Sandbox radio
2. User clicks "Connect Salesforce"
3. Component sets `loading = true`; button becomes "Connecting…" + spinner; disabled
4. Component calls `salesforce-oauth-initiate` Edge Function (POST with `{ org_id, is_sandbox }`)
5. On success: browser navigates to returned `auth_url` — component is unmounted, loading state irrelevant
6. On fetch error: set inline error with "unknown" copy; reset loading state

### Post-OAuth Return

After successful OAuth, `salesforce-oauth-callback` redirects back to `settings?tab=Integrations`. Settings page re-mounts, `SalesforceConnection` fetches `salesforce_connections` for the org, renders connected state. No additional component logic needed for success path.

### Disconnect Sequence

1. User clicks "Disconnect"
2. Component sets `disconnecting = true`; button becomes "Disconnecting…" + spinner; disabled
3. Component calls `salesforce-oauth-disconnect` Edge Function (POST with `{ org_id }`)
4. On success: clear connection state, re-render disconnected state
5. On error: reset `disconnecting = false`; show inline error banner with "unknown" copy

### Data Fetching

- On mount: `supabase.from('salesforce_connections').select('sf_username, is_sandbox').eq('org_id', orgId).maybeSingle()`
- Loading skeleton: show card with logo + name + description; footer replaced with a `h-8 bg-gray-100 rounded animate-pulse w-full` placeholder
- Null result = disconnected state; non-null result = connected state
- Error on fetch = render disconnected state (D-16 graceful degradation — never blocks)
