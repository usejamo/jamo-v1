**Risk B mitigation — two-step lookup summary:**
The snapshot key mismatch (Pitfall 1 / Risk B) is resolved by:
1. At CTA-click (`onCtaClick`): embed `originating_snapshot` in `cta_payload` before calling `handleSendMessage`.
2. At edge `ask_user` dispatch: read snapshot from `cta_payload`, write into `active_task.originating_snapshot` (awaited).
3. At `propose_edit` arrival (`AIChatPanel.tsx:501-507`): try Map lookup first (existing path), fall back to `activeTask.originating_snapshot` if null.

This composes with D-01 ("one write, both jobs") — the same `await`ed write that establishes durable resume state also carries the attribution snapshot.
