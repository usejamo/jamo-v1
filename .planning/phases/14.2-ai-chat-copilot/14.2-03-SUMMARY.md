## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] UniqueID extension does not populate attrs.id in headless TipTap editor**
- **Found during:** Task 2 test authoring
- **Issue:** `@tiptap/extension-unique-id` assigns IDs via document transactions that require a mounted DOM; headless editor test returned empty string for `node.attrs.id`
- **Fix:** Created `ParagraphWithId` custom TipTap Node extension in test file that parses `data-id` attribute directly, enabling known `KNOWN_PARA_ID = 'test-para-001'` in content
- **Files modified:** `pendingEditsPlugin.spec.ts`
- **Commit:** 5f12f89

**2. [Rule 1 - Design] djb2 hash used instead of SHA-256**
- **Found during:** Task 1 implementation
- **Issue:** Plan specified "SHA-256 first 8 chars" but Web Crypto SHA-256 is async — unusable synchronously inside ProseMirror decoration builders
- **Fix:** Used djb2 variant (synchronous, produces 8-char hex) — same collision properties for the staleness use case
- **Files modified:** `decorations.tsx`
- **Commit:** 5dfeca4
