# Phase 14.2 Plan 02: TypeScript Type Contracts Summary

JWT-style type contracts for Phase 14.2 inline editor diffs and AI co-pilot — `PendingEdit` identity type plus action queue types with direct field mapping and operation label constants.

## What Was Built

### workspace.ts extensions

- `ChangeOperation` union: `'replace' | 'insert_after' | 'delete'`
- `ChangeResolution` union: `'accepted' | 'rejected' | 'auto_rejected_stale' | 'not_reached' | 'pending'`
- `PendingEdit` interface with all identity/persistence fields (`id`, `message_id`, `change_index`, `section_key`, `created_at`) plus direct field mapping from `ProposeEditChange` (no renaming of `operation`, `before_html`, `after_html`)
- `anchorFrom`/`anchorTo` runtime-only fields with `@runtime_only` JSDoc
- `anchor_hash` field with staleness formula documented: `normalizedText(paragraph) + '|' + paragraphId + '|' + originalHtml`
- `SectionEditorState.pending_edits: PendingEdit[]` field
- 6 new `WorkspaceAction` types: `SET_PENDING_EDITS`, `ACCEPT_PENDING_EDIT`, `REJECT_PENDING_EDIT`, `CLEAR_PENDING_EDITS`, `AUTO_REJECT_STALE_EDITS`, `BATCH_ACCEPT_PENDING_EDITS`
- `BATCH_ACCEPT_PENDING_EDITS` JSDoc documents "silently skipped" behavior for already-resolved edits
- `SectionEditorHandle.materializePendingEdits` method added

### chat.ts extensions

- `ChangeType` union type (same values as `ProposeEditChange.operation` — directly assignable)
- `CHANGE_TYPE_LABELS` constant with `replace→EDIT`, `insert_after→INSERT`, `delete→DELETE` mapping and aria labels
- `ComplianceIssue.changes?: ProposeEditChange[]` optional field for proposed fixes
- `ProposeEditState.resolutions` extended to include `'auto_rejected_stale' | 'not_reached'`
- `ActionItemType`, `ActionItemCtaTool` types
- `PendingActionItem` interface with full persistence fields (`proposal_id`, `run_id`, `created_at`, `updated_at`, `rationale?`, `confidence?`)
- `WalkthroughStage`, `QueueItemTerminalState` types
- `ActiveTask` interface with `status`, `started_at`, `completed_at?`, `source_action_item_id?`, `content_hash`, `last_updated`
- D-49 JSDoc on `ChatRow.section_target_id`
