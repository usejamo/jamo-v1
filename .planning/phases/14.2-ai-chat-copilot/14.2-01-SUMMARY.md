## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Added DROP INDEX before composite PK in migration 41**
- **Found during:** Task 3
- **Issue:** The existing migration 32 created `chat_sessions_proposal_id_idx` as a UNIQUE INDEX on `proposal_id`. Dropping only `chat_sessions_pkey` before adding composite PK would leave the unique index conflicting.
- **Fix:** Added `DROP INDEX IF EXISTS chat_sessions_proposal_id_idx` before `DROP CONSTRAINT IF EXISTS chat_sessions_pkey`
- **Files modified:** supabase/migrations/20260515000041_chat_sessions_per_user.sql
- **Commit:** ed21c55

**2. [Rule 1 - Bug] Added DROP POLICY for original org_isolation policy in migration 41**
- **Found during:** Task 3
- **Issue:** Original migration 32 created a single `chat_sessions_org_isolation` FOR ALL policy. Migration 41 drops per-operation policies but would fail to replace the catch-all `chat_sessions_org_isolation` policy.
- **Fix:** Added `DROP POLICY IF EXISTS "chat_sessions_org_isolation" ON chat_sessions` to the policy cleanup block
- **Files modified:** supabase/migrations/20260515000041_chat_sessions_per_user.sql
- **Commit:** ed21c55
