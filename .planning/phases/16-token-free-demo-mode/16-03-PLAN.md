<objective>
Build `demo-capture-fixture` (D-04): a super_admin-only, service-role edge function that snapshots a live proposal — generated inside the demo org (D-05) — into a new versioned `demo_fixtures` record with its sections (content HTML incl. `data-placeholder-id` spans + compliance_flags), approved assumptions, RFP study fields, extracted RFP text, and its pre-computed RFP `chunks` (embeddings). Each capture is a new monotonic version bound to the source proposal's `template_id`; the newest becomes the single `active` version.

Purpose: Fixtures are captured, never hand-edited (SPEC Req 2). Capturing only inside the demo org guarantees no real client content is ever baked into a shipped fixture (D-05 confidentiality).
Output: 1 deployed edge function + grep-acceptance test.
</objective>
