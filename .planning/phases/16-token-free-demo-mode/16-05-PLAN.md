<objective>
Build `demo-reset`: a super_admin-only edge function that takes the session's `demo_run_id` (run-scoped, caller-verified — D-10, never account-inferred under the shared login), verifies the run's proposal is in the demo org AND `status='draft'` AND tracked by `demo_runs` (triple-guard), then hard-deletes the proposal (FK-cascades sections/assumptions/cloned chunks/chats/chat_sessions/section_versions) PLUS an explicit delete of the run's `proposal_documents` (+cascaded `document_extracts`, which are FK `SET NULL` not cascade — Pitfall 1) PLUS the `demo_runs` row. The shared canonical RFP Storage file is referenced by every run and is retained (D-06). Cleanup logic lives in a shared `_shared/demoRunCleanup.ts` so the sweep (16-06) reuses one implementation, never a divergent second one.

Purpose: A real DB-deleting reset (the old control deleted zero rows) that returns the presenter to a clean pre-upload state and refuses to touch any non-demo proposal or another session's run.
Output: 1 deployed edge fn + shared cleanup module + grep-acceptance test.
</objective>
