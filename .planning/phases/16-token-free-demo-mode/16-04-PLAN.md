<objective>
Build `demo-run-start`: the super_admin-only edge function that, for the standard template, loads the active fixture, validates it against the current `template_sections` (Req 7 — loud pre-population failure), then in one atomic sequence materializes a fresh draft proposal in the demo org owned by the caller — sections (content='complete' from the fixture), approved assumptions, a `proposal_documents` row (+`document_extracts` from `rfp_extract_text`) pointing at the shared canonical RFP Storage file (D-06), cloned RFP chunks via the `clone_demo_fixture_chunks` RPC (Decision C — real embeddings, no model call), and a `demo_runs` tracking row. Purpose: Fresh isolated proposal per run (Req 5) with real indexed RFP content (Req 3) and no blank sections (Req 7). Concurrency isolation and reset/sweep targeting flow from the `demo_runs` row.
Output: 1 deployed edge fn + a shared validation module (Deno + a mirrored Vitest-testable src copy) + tests.
</objective>
