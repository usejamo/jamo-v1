## Hook design notes

- **Pure pattern:** `computeTerminalWrites` and `computeWrittenMessageIds` exported separately. Neither calls React, Supabase, or any side-effecting API. The hook itself is a thin `useEffect + useRef` shell.
- **writtenRef location:** Inside the hook (line 209), not in AIChatPanel. Prevents AIChatPanel from owning a leaking ref and keeps the once-per-message guarantee local to the writer.
- **Free-text-skip + written-id record (Pitfall 7):** `computeWrittenMessageIds` returns message ids INCLUDING free-text skips so the hook can mark them written even when no write is dispatched. Prevents re-evaluation thrash on re-render.
- **Permissive WorkspaceStateLike:** `sections: Record<string, unknown>`. Narrowed internally via `sectionRaw as WorkspaceSectionLike | undefined`. Accepts the concrete `WorkspaceState` from SectionWorkspaceContext without forcing an index signature onto `SectionEditorState`.
- **Dependency injection:** `deps: { buildResolvedItemEntry, appendResolvedItem }` parameter. AIChatPanel supplies real implementations; tests don't need them because they assert against the pure selectors directly (B3 closure).

## Deviations from Plan

### Rule 3 — Type-compatibility fix

**[Rule 3 — Blocking] Relaxed `WorkspaceStateLike.sections` to `Record<string, unknown>`**
- **Found during:** tsc verification after Task 3 wire-up
- **Issue:** `SectionEditorState` (from `src/types/workspace.ts`) lacks an index signature; the original `WorkspaceSectionLike & { [key: string]: unknown }` typing was not assignable from `WorkspaceState`.
- **Fix:** Changed `sections: Record<string, WorkspaceSectionLike>` to `sections: Record<string, unknown>` and narrowed via `sectionRaw as WorkspaceSectionLike | undefined` inside `computeTerminalWrites` and `computeWrittenMessageIds`. Type-safe at consumption, structurally permissive at the boundary. No `as any` introduced.
- **Files modified:** `src/hooks/useResolvedItemsWriteOnTerminal.ts`
- **Commit:** included in a6d108e
