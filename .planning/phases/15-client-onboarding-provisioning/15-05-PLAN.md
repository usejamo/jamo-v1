<objective>
Build `admin-invites-lifecycle` — the super_admin cross-org invite management function backing the pending-invites panel (req 8). One function with three actions: `list` (all pending/recent invites, joined to org name), `resend` (revoke-then-reissue per Pitfall 4 — NOT a second `inviteUserByEmail` on a still-pending email), and `revoke` (delete auth user + mark invites row revoked, D-06).

Purpose: Completes the platform-admin lifecycle surface. Resend is deliberately implemented as revoke+create to sidestep GoTrue's ambiguous re-invite behavior.
Output: One edge function + Deno test scaffold.
</objective>
