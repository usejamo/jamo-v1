### Human Verification Required

#### 1. Visual Style Fidelity in Exported DOCX

**Test:** Upload a DOCX template with distinctive heading styles (e.g., bold red Heading 1, blue Heading 2). Export a proposal that uses both heading levels. Open the downloaded `.docx` in Microsoft Word.
**Expected:** Heading styles match the uploaded template — fonts, colors, and spacing — not Calibri defaults.
**Why human:** The code correctly swaps `styles.xml`, `theme1.xml`, and `numbering.xml` at the blob level. Whether Word correctly interprets those injected XML parts and renders them as expected requires visual inspection of a rendered document.

#### 2. Style Inspection Warning in TemplatesTab UI

**Test:** Upload a DOCX template that is intentionally missing `Heading 2` and `Heading 3` style definitions. Wait for processing to complete (parse_status = 'ready'). View Settings > Templates.
**Expected:** An amber warning badge appears on that template row listing "Missing styles: Heading 2, Heading 3" with a "How to fix in Word" link.
**Why human:** Requires the live Edge Function to run `inspectDocxStyles`, write to `style_inspection` column, and the TemplatesTab to re-fetch. Cannot verify E2E without a running Supabase environment.

#### 3. 10MB Upload Rejection UX

**Test:** Attempt to upload a file larger than 10MB through the template upload dropzone in Settings.
**Expected:** Error message appears immediately with the actual file size in MB and "Try compressing images in Word before re-uploading." No upload request is made.
**Why human:** Client-side validation is code-verified but rendered error display and absence of network request require browser DevTools confirmation.

#### 4. Nudge Appears Once and Respects localStorage

**Test:** Clear localStorage. Export a proposal with no template configured. Note nudge appears. Click "Maybe later". Export again.
**Expected:** Nudge appears after first export, disappears after dismiss, does not reappear on second export.
**Why human:** localStorage state and UI interaction require browser testing.
