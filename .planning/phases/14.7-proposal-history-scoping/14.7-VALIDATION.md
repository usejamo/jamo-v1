## Sampling Rate

- **After every task commit:** Run `npm run test:run` (client tasks) / grep-acceptance (migration + edge tasks)
- **After every plan wave:** Run `npm run test:run` + `npm run build`
- **After Plan 06 (deploy):** Run the live SQL suites (`verify-eligibility.sql`, `verify-write-gating.sql`) via Supabase MCP
- **Before `/gsd-verify-work`:** Client suite green + all 7 BRIEF cases + 3 fail-closed edge cases PASS live + 14.6 regression unchanged
- **Max feedback latency:** ~15 seconds (client suite); live SQL is a manual gate at Plan 07
